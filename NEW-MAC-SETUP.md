# Настройка второго мака — с самого начала

Инструкция для чистого мака, на котором ещё ничего не стоит. Выполнять сверху
вниз, ничего не пропуская. Каждый шаг говорит, **что сделать** и **что должно
появиться на экране** — если появилось не то, смотри «Если что-то пошло не так»
в конце шага.

Всего примерно 40 минут, из них половина — ожидание загрузок.

---

## Как пользоваться Терминалом

Терминал понадобится почти в каждом шаге. Открывается так:

1. Нажать **Cmd + Пробел** (откроется поиск Spotlight)
2. Набрать `Терминал` (или `Terminal`, если система на английском)
3. Нажать **Enter**

Откроется окно с чёрным или белым фоном и мигающим курсором.

**Как вводить команды из этой инструкции:**

1. Выделить строку в инструкции и скопировать — **Cmd + C**
2. Переключиться в окно Терминала
3. Вставить — **Cmd + V**
4. Нажать **Enter**

Не набирай команды вручную — легко ошибиться в символе, и ничего не заработает.

**Важно:** если Терминал попросит пароль от мака — вводи его вслепую. Символы
не отображаются, даже точками. Это нормально. Ввёл — нажал Enter.

# Шаг 1. Инструменты разработчика Apple

Нужны, чтобы работал `git` — без него не скачать твой набор настроек.

**Что сделать:**

1. Открыть Терминал
2. Вставить и нажать Enter:

```
xcode-select --install
```

3. Появится окно **«Программа командной строки xcode-select требует
   инструменты командной строки»** → нажать кнопку **«Установить»**
4. Принять лицензионное соглашение
5. Ждать 5–15 минут, пока идёт полоса загрузки

**Проверка.** Когда загрузка закончилась, вставить в Терминал:

```
git --version
```

Должно появиться примерно: `git version 2.50.1 (Apple Git-155)`

**Если что-то пошло не так.** Написало `command line tools are already
installed` — значит уже стоит, просто иди дальше.

# Шаг 2. Node.js

Нужен для дополнительных инструментов Claude (браузер, поиск, документация).

**Что сделать:**

1. Открыть в браузере: **https://nodejs.org**
2. Нажать большую зелёную кнопку с надписью **LTS** (слева)
3. Скачается файл вида `node-v24.x.x.pkg` — он попадёт в папку «Загрузки»
4. Открыть «Загрузки», дважды кликнуть по этому файлу
5. В установщике нажимать **«Продолжить»** → **«Продолжить»** → **«Принимаю»**
   → **«Установить»**
6. Ввести пароль от мака, когда попросит
7. Дождаться надписи **«Установка выполнена успешно»** → **«Закрыть»**

**Проверка.** Закрыть Терминал полностью (Cmd + Q) и открыть заново — это
обязательно, иначе он не увидит новую программу. Затем вставить:

```
node -v
```

Должно появиться: `v24.x.x` (цифры могут отличаться, главное — что-то появилось).

**Если что-то пошло не так.** Пишет `command not found` — Терминал не был
перезапущен. Закрыть через **Cmd + Q** (не крестиком!) и открыть заново.

# Шаг 3. Проверка, что остальное уже есть

Две программы обычно идут в комплекте с macOS. Проверим.

**Что сделать.** Вставить в Терминал по одной строке, каждую с Enter:

```
jq --version
```

```
python3 -V
```

**Что должно появиться:** `jq-1.7.1` и `Python 3.13.x` (версии могут отличаться).

**Если что-то пошло не так.**

- Нет `jq` → скачать с **https://jqlang.github.io/jq/download/**. Без него не
  будет работать строка состояния внизу окна Claude. На всё остальное не влияет.
- Нет `python3` → скачать с **https://www.python.org/downloads/macos/**. Без
  него Claude не будет читать ответы вслух.

Оба — не критично. Можно идти дальше и вернуться потом.

# Шаг 4. Установка Claude Code

**Что сделать:**

1. Вставить в Терминал и нажать Enter:

```
curl -fsSL https://claude.ai/install.sh | bash
```

2. Пойдёт загрузка, в конце появится сообщение об успешной установке

**Проверка.** Вставить:

```
claude --version
```

Должно появиться: `2.1.x (Claude Code)` — версия не ниже 2.1.

**Если что-то пошло не так.** Пишет `command not found: claude` — Терминал не
знает, где искать программу. Вставить эти две строки по очереди:

```
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
```

```
source ~/.zshrc
```

И снова проверить `claude --version`.

# Шаг 5. Вход в аккаунт

**Что сделать:**

1. Вставить в Терминал:

```
claude
```

2. Спросит про тему оформления — выбрать стрелками, нажать Enter
3. Появится вопрос про способ входа — выбрать **Claude account with
   subscription** (не Anthropic Console!) и нажать Enter
4. Откроется браузер со страницей входа
5. Войти **тем же аккаунтом**, что на первом маке
6. Появится код — скопировать его, вернуться в Терминал, вставить, Enter
7. Терминал скажет, что вход выполнен

**Проверка.** Не выходя из Claude, набрать и нажать Enter:

```
/status
```

Должны показаться твой аккаунт и активная подписка.

**Как выйти из Claude:** набрать `/exit` и Enter. Или нажать **Ctrl + C** дважды.

# Шаг 6. Установка VS Code

Это редактор кода, в котором удобно работать с Claude.

**Что сделать:**

1. Открыть в браузере: **https://code.visualstudio.com/download**
2. Нажать кнопку **Mac** → выбрать **Apple Silicon** (если мак новее 2020 года)
3. Скачается архив `VSCode-darwin-arm64.zip` в «Загрузки»
4. Дважды кликнуть по архиву — рядом появится приложение **Visual Studio Code**
5. **Перетащить** это приложение в папку **«Программы»** (Applications) —
   это важно, иначе часть функций не заработает
6. Открыть «Программы», дважды кликнуть по Visual Studio Code
7. Появится окно **«Это приложение загружено из интернета»** → нажать
   **«Открыть»**

# Шаг 7. Команда `code` в Терминале

**Что сделать:**

1. В открытом VS Code нажать **Cmd + Shift + P** — сверху появится строка поиска
2. Начать печатать: `shell command`
3. В списке выбрать **Shell Command: Install 'code' command in PATH**
4. Нажать Enter, ввести пароль от мака

**Проверка.** Перезапустить Терминал (**Cmd + Q**, открыть заново), вставить:

```
code --version
```

Должны появиться три строки с версией.

---

# Шаг 8. Расширение Claude для VS Code

**Что сделать (самый простой способ):**

1. Открыть VS Code
2. Нажать **Ctrl + `** (клавиша с обратным апострофом, под Esc) — снизу
   откроется встроенный терминал
3. Набрать `claude` и нажать Enter
4. Расширение установится само

**Если не сработало** — вставить в обычный Терминал:

```
code --install-extension anthropic.claude-code
```

**Проверка.** В VS Code нажать **Cmd + Esc** — справа должна открыться панель
Claude.

# Шаг 9. Загрузка твоего набора настроек

Здесь приезжают все скиллы, агенты, команды и плагины с первого мака.

**Что сделать:**

1. Вставить в Терминал по одной строке:

```
cd ~/Documents
```

```
git clone https://github.com/Aliwers/claude-code-setup.git
```

2. Если попросит логин и пароль GitHub — значит репозиторий приватный.
   Тогда сначала: скачать **https://cli.github.com**, установить, и выполнить
   `gh auth login` (выбирать: GitHub.com → HTTPS → Login with a web browser),
   после чего повторить `git clone`.

3. Перейти в скачанную папку:

```
cd ~/Documents/claude-code-setup
```

4. Запустить установку:

```
./install.sh
```

5. Скрипт покажет, что собирается сделать, и спросит **«Продолжить? [y/N]»** —
   набрать `y` и нажать Enter

**Что произойдёт:** в твою папку настроек лягут 105 скиллов, 38 агентов,
15 команд, правила, хуки и звуки. Затем установятся 24 плагина и 4 дополнительных
инструмента. Это займёт несколько минут, будет много текста — так и должно быть.

**В конце появится:** `Готово.` и список того, что осталось настроить руками.

**Если что-то пошло не так.** Написало `Не найден claude CLI` — значит Шаг 4
не завершился. Вернуться к нему.

# Шаг 10. Ключи и подключения

В репозитории намеренно нет ни одного пароля и токена — их нужно вписать здесь.

## 10.1. Токен GitHub

**Что сделать:**

1. Открыть **https://github.com/settings/tokens**
2. Нажать **Generate new token** → **Generate new token (classic)**
3. В поле Note написать: `second macbook`
4. Поставить галочки: **repo** и **read:org**
5. Внизу нажать **Generate token**
6. Скопировать появившийся код (начинается на `ghp_`) — **он показывается
   только один раз**
7. Открыть файл настроек командой:

```
open -e ~/.claude/settings.json
```

8. Откроется TextEdit. В самое начало, сразу после первой скобки `{`,
   вставить строку (заменив `ghp_ВСТАВЬ_СЮДА` на свой код):

```
  "env": { "GITHUB_PERSONAL_ACCESS_TOKEN": "ghp_ВСТАВЬ_СЮДА" },
```

9. Сохранить: **Cmd + S**, закрыть окно

## 10.2. Подключения по входу в аккаунт

Figma, Supabase, Miro, Stripe, Vercel, higgsfield — здесь пароли не нужны,
только вход.

1. Запустить `claude` в Терминале
2. Набрать `/mcp` и Enter
3. Пройти по каждой ссылке, войти в свой аккаунт

## 10.3. Отдельные ключи

21st.dev и ElevenLabs требуют своих API-ключей. Команды для них лежат в файле
`MCP.md` в скачанной папке:

```
open -e ~/Documents/claude-code-setup/MCP.md
```

## 10.4. Gmail, Календарь, Google Диск

Ставить ничего не нужно. Они подключены к аккаунту Claude и появятся сами,
потому что аккаунт тот же.

# Шаг 11. Финальная проверка

Запустить в Терминале:

```
claude
```

И по очереди набрать команды:

| Набрать | Что должно быть |
|---|---|
| `/status` | твой аккаунт и активная подписка |
| `/plugin` | список из 24 плагинов |
| `/mcp` | 4 инструмента сразу, остальные — после Шага 10.2 |
| `/skills` | около 105 скиллов |

Внизу окна должна быть серая строка: **название модели, папка, ветка**.
Пустая строка — значит нет `jq`, вернись к Шагу 3.

**Последнее.** Скопировать это в Claude и отправить:

> Я поставил набор скиллов, агентов и команд в `~/.claude`. Прочитай
> `~/.claude/ECC-INSTALLED.md` и `~/.claude/settings.json`, потом расскажи
> своими словами: какие скиллы у меня появились, какие агенты и когда ты будешь
> их звать сам, какие слэш-команды есть. Отдельно скажи, что из этого не
> заработает без донастройки.

# Что изменится в поведении и как выключить

Набор включает несколько привычек, которые могут удивить на новом маке:

| Что происходит | Как выключить |
|---|---|
| Claude читает ответы вслух по-русски | вставить в Терминал: `touch ~/.claude/.speak-off` |
| Звук после каждого ответа | открыть `~/.claude/settings.json`, удалить строку со словом `afplay` |
| Точка ● в заголовке окна VS Code | там же удалить блок со словом `vscode-attention` |
| Расходуется много токенов | там же заменить `"model": "opus"` на `"sonnet"`, а `"effortLevel": "xhigh"` на `"medium"` |
| Claude отвечает очень коротко и «лениво» | набрать в сессии: `/ponytail lite` |

# Если понадобится всё откатить

Перед установкой скрипт сделал полную резервную копию. Вернуть как было:

```
tar xzf ~/.claude/backups/pre-setup-*.tgz -C ~/.claude
```

Удалить набор полностью:

```
cd ~/.claude && rm -rf skills agents commands rules hooks sounds
```

# ⚠️ Сделать на ПЕРВОМ маке

На первом маке в файле `~/.claude/settings.json` токен GitHub записан открытым
текстом. В репозиторий он не попал — проверено по всей истории, там только
заглушка. Но файл с настоящим паролем находится в одном движении от случайной
публикации.

**Что сделать:**

1. Открыть **https://github.com/settings/tokens**
2. Найти старый токен → **Delete**
3. Создать два новых — отдельно для каждого мака (как в Шаге 10.1)
4. Вписать каждому маку свой
