# Установка — пошагово и без сюрпризов

Читать до запуска `install.sh`. Отвечает на главный вопрос: **что скрипт трогает,
а что нет.**

---

## 0. Требования

| Что | Зачем | Проверить |
|---|---|---|
| Claude Code + платная подписка | без неё набор бесполезен | `claude --version` (нужна ≥ 2.1) |
| `python3` | хуки озвучки и метки окна | `python3 -V` |
| `jq` | строка статуса с моделью и веткой | `jq --version` |
| `node` ≥ 18 | часть скиллов и MCP через `npx` | `node -v` |
| macOS | **только** для хуков и звуков (`say`, `afplay`) | — |

На Linux/Windows всё остальное работает; блок `hooks` из `settings.json` убрать.

---

## 1. Что скрипт делает — полный список

```
~/.claude/
├── skills/     ← добавляет 105 каталогов
├── agents/     ← добавляет 38 файлов
├── commands/   ← добавляет 15 файлов
├── rules/      ← добавляет 23 набора
├── hooks/      ← добавляет 2 скрипта
├── sounds/     ← добавляет 48 звуков
├── settings.json          ← ставит, ТОЛЬКО если его ещё нет
├── settings.suggested.json ← иначе кладёт эталон рядом
└── backups/pre-setup-*.tgz ← бэкап всего перечисленного ДО изменений
```

Плюс через `claude` CLI: 3 маркетплейса, 24 плагина, 4 MCP-сервера — все в
пользовательскую область (`--scope user`).

## 2. Чего скрипт НЕ делает

- **Не трогает проекты.** Ни одного файла вне `~/.claude`. Локальные
  `<проект>/.claude/`, `CLAUDE.md`, `.mcp.json` остаются как были. Правила
  проекта по-прежнему главнее глобальных.
- **Не перезаписывает существующий `settings.json`.** Если он есть — рядом
  ляжет `settings.suggested.json`, сливать вручную.
- **Не удаляет** ничьих скиллов, агентов и команд. Только добавляет и
  перезаписывает **одноимённые**.
- **Не трогает** историю, память, сессии, планы (`projects/` `sessions/`
  `plans/` `file-history/`).
- **Не содержит ключей.** Ни одного токена внутри — всё своё, по [MCP.md](MCP.md).

## 3. Единственный реальный риск — совпадение имён

Если у тебя уже есть, скажем, свой скилл `seo` или агент `code-reviewer` —
одноимённый из набора его перезапишет. Поэтому скрипт **сначала показывает
список совпадений и спрашивает подтверждение**:

```
  ! уже есть и будет перезаписано (3 шт., копия в бэкапе выше):
  skills/seo
  agents/code-reviewer
  commands/pr
Продолжить? [y/N]
```

Ответить `n` — не тронуто ничего. Всё равно откатить можно из бэкапа (см. §6).

## 4. Запуск

```bash
unzip claude-code-setup.zip
cd claude-code-setup
./install.sh          # спросит про перезапись
./install.sh -y       # не спрашивать
```

Скрипт идемпотентен: повторный запуск безопасен, каждый раз делает свежий бэкап.

## 5. После установки

```bash
claude          # запустить
/plugin         # должно быть 24 плагина
/mcp            # 4 сервера; остальные — по MCP.md
```

Что заметно сразу и как выключить:

| Поведение | Откуда | Выключить |
|---|---|---|
| Клод читает ответы вслух по-русски | Stop-хук `speak-response.py` | `touch ~/.claude/.speak-off` |
| Звук по завершении ответа | Stop-хук `afplay` | убрать строку из `settings.json` |
| Точка `●` в заголовке окна VS Code | `vscode-attention.py` | убрать блок из `settings.json` |
| Модель `opus`, усилие `xhigh` | `settings.json` | `"model": "sonnet"`, `"effortLevel": "medium"` |
| Интерфейс и ответы на русском | `"language": "ru"` | сменить или убрать ключ |
| Режим «ленивого сеньора» | плагин ponytail | `/ponytail lite` или `stop ponytail` |

**Про расход токенов.** `opus` + `effortLevel: xhigh` жрут заметно больше
дешёвых настроек. Если план не топовый — начать с `sonnet` и `medium`, поднять
потом.

**Про правила.** `rules/README.md` и `rules/common/*` грузятся в **каждую**
сессию — это ~6 КБ инструкций про стиль, тесты, безопасность, ревью. Языковые
наборы (`rules/typescript/`, `rules/python/` и т.д.) лежат библиотекой с
`paths:`-фронтматтером и включаются только под свои файлы. Не нравится базовый
свод — удалить `~/.claude/rules/common/`, остальное продолжит работать.

## 6. Откат

```bash
ls ~/.claude/backups/                       # найти pre-setup-ДАТА.tgz
tar xzf ~/.claude/backups/pre-setup-*.tgz -C ~/.claude   # вернуть как было
```

Полностью снести набор:

```bash
cd ~/.claude && rm -rf skills agents commands rules hooks sounds
claude plugin list                          # и удалить лишние через /plugin
```

## 7. Что сказать своему Claude Code

Скопировать в первую сессию после установки:

> Я поставил набор скиллов, агентов и команд в `~/.claude`. Прочитай
> `~/.claude/ECC-INSTALLED.md` и `~/.claude/settings.json`, потом расскажи
> своими словами: какие скиллы у меня появились, какие агенты и когда ты будешь
> их звать сам, какие слэш-команды есть. Отдельно скажи, что из этого не
> заработает без донастройки.

Дальше по ситуации:

- «Покажи, что тянет контекст» → скилл `context-budget`
- «Убери из набора лишнее» → скилл `config-gc`, проведёт по чистке с
  подтверждением каждого удаления
- «Настрой правила под мой проект» → скопирует `~/.claude/rules/common/` +
  нужный стек в `<проект>/.claude/rules/`
- Планирование фичи → `/plan` или `/plan-prd`
- Ревью перед коммитом → `/ecc-code-review` (встроенный `/code-review` отдельно)

## 8. Диагностика

| Симптом | Причина |
|---|---|
| Строка статуса пустая | нет `jq` |
| Не читает вслух | нет `python3`, не macOS, или лежит `~/.claude/.speak-off` |
| Плагин есть, инструменты не появились | нужна авторизация: `/mcp` в сессии |
| `/plugin` показывает не 24 | часть маркетплейсов не добавилась — перезапустить `install.sh` |
| Скиллы не подхватились | перезапустить `claude`, они читаются на старте сессии |
